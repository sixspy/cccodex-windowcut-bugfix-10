# 抬代修复卡（BUGFIX-10 窗重开抬代）

- 择定日期：2026-11-21（**当日禁止改口**）
- 缺陷：重开空桩登记只在台账写抬代，`windows.generation` 不涨、旧物化仍挂当前代、还误把窗口改回「开启」，世代账错乱。

## 择定路径：甲路径（唯一正确性口径，两路径不得混用）

**重开同事务 `generation+1` 并作废旧物化；任一步失败，世代与作废整体回滚。**

乙路径（旧代保留快照、新代只接补丁表）当日禁用：请求 `mode=增量补丁` 视为偏离本卡 → **拒写并记审计「抬代偏了」**。

## 落库语义

1. **占锁先行**：重开锁 `reopen:{wid}` 独立事务先落库；两人同时重开同窗，后到只记争用（`contention_log`），不写业务。
2. **业务同事务**：`windows.generation+1` → 删除本窗旧物化行 → `reopen_ledger` 记「已抬代」→ 审计 `reopen_bump`（含作废明细）。任一步失败整体回滚，世代与作废同生同灭。
3. **不误开窗**：窗口状态保持「已关闭」；新代物化由物化服务按当前世代重出，分区键 `{窗名}-g{世代}`，世代与物化同源。
4. **列表不假抬**：窗口列表直出库列世代，不做 `+1` 假抬代。

## 作废 = 删除旧物化行的理由

对账只认本窗最新物化行，且对账服务不在本次可改范围；若仅标记「已作废」而留行，旧物化仍挂当前代、对账继续判齐，五处不同态。故作废以删除落库，被删行明细写入审计载荷留痕。

## 五处同态验收（重开 1→2 后）

| 处 | 同态判据 |
|----|----------|
| 重开台账 | 最新行 `1→2`，状态「已抬代」 |
| 世代 | `windows.generation=2`，状态仍「已关闭」 |
| 物化 | 旧 `g1` 行已删；重物化出 `W-1101-g2` |
| 对账 | 新代未物化前 `aligned=false`；重物化后对齐 `g2` |
| 审计 | `reopen_bump` 留痕，载荷含作废明细 |
